# Первая лабораторная работа по ПАТД

## Общее описание

Проект представляет собой **калькулятор полиномов** на C, реализующий обобщённый (типонезависимый) тип полинома `Polynomial`. Полином хранит массив коэффициентов произвольного типа, а конкретный тип задаётся через структуру дескриптора `TypeInfo` — таблицу операций (сложение, умножение, ноль, единица, сравнение, преобразование в строку и т.д.).

Благодаря этому один и тот же код полинома работает с разными типами коэффициентов. В работе реализованы два типа:

- **`double`** — вещественные коэффициенты (`GetTypeInfoDouble`).
- **`Complex`** — комплексные коэффициенты (`GetTypeInfoComplex`).

Над полиномами поддерживаются сложение, умножение, умножение на скаляр и вычисление значения в точке. Программа предоставляет интерактивное меню командной строки для создания полиномов и выполнения операций над ними.

### Компоненты

| Файл | Описание |
|------|----------|
| `typeinfo.h` | Структура `TypeInfo` — таблица указателей на операции типа: `add`, `multiply`, `alloc`, `increment`, `zero`, `one`, `set`, `compare`, `toString`, а также размер элемента `size`. За счёт неё полином не зависит от конкретного типа коэффициентов |
| `typeinfodouble.h / .c` | Реализация `TypeInfo` для типа `double`: `GetTypeInfoDouble()` возвращает дескриптор, `NewDouble(val)` создаёт значение |
| `typeinfocomplex.h / .c` | Реализация `TypeInfo` для комплексных чисел: `GetTypeInfoComplex()` возвращает дескриптор, `NewComplex(re, im)` создаёт значение |
| `polynomial.h / .c` | **Обобщённый полином** `Polynomial` (массив коэффициентов `coeffs`, их число `coeffCount`, дескриптор `type`) и операции: создание, заполнение, сложение, умножение, умножение на скаляр, вычисление в точке, преобразование в строку |
| `polynomial_errors/polyerr.h / .c` | Перечисление кодов ошибок `PolyError` и функция `PolyError_description()` с их текстовыми описаниями |
| `utils.h` | Вспомогательные макросы `min` / `max` |

## Функциональность

### Операции над полиномом (`polynomial.h`)

| Функция | Описание |
|---------|----------|
| **`newPolynomial`** | Создаёт полином заданной степени для указанного типа |
| **`freePolynomial`** | Освобождает память полинома |
| **`fillPolynomial`** | Заполняет полином массивом коэффициентов |
| **`sumPolynomial`** | Складывает два полинома |
| **`multPolynomial`** | Перемножает два полинома |
| **`multPolynomialByScalar`** | Умножает полином на скаляр |
| **`computePolynomial`** | Вычисляет значение полинома в заданной точке |
| **`polynomialToString`** | Возвращает строковое представление полинома |

Полином представлен структурой:

```c
typedef struct {
    size_t coeffCount;     // число коэффициентов (степень + 1)
    void* coeffs;          // массив коэффициентов произвольного типа
    const TypeInfo* type;  // дескриптор типа коэффициентов
} Polynomial;
```

### Обобщённость через `TypeInfo`

Полином не знает, с каким типом он работает, — всю арифметику он выполняет через указатели на функции из `TypeInfo`. Чтобы добавить новый тип коэффициентов, достаточно реализовать соответствующий дескриптор (по образцу `typeinfodouble.c` / `typeinfocomplex.c`) и передать его в `newPolynomial`.

### Обработка ошибок

Все операции возвращают код `PolyError`:

| Код | Значение |
|-----|----------|
| `POLY_OK` | Успех |
| `POLY_ERR_NOMEM` | Недостаточно памяти |
| `POLY_ERR_NULLARG` | Нулевой аргумент |
| `POLY_ERR_TYPE` | Разные типы полиномов |
| `POLY_ERR_SIZE` | Несовпадение размеров |
| `POLY_ERR_COEFF_COUNT` | Нулевое число коэффициентов |

## Интерфейс пользователя

После запуска доступно главное меню:

```
┌─────────────────────────────────────┐
│        Калькулятор полиномов        │
├─────────────────────────────────────┤
│  1  Создать полином                 │
│  2  Показать полином                │
│  3  Список всех полиномов           │
│  4  Сложить два полинома            │
│  5  Умножить два полинома           │
│  6  Умножить полином на скаляр      │
│  7  Вычислить полином в точке       │
│  8  Удалить полином                 │
│  0  Выход                           │
└─────────────────────────────────────┘
```

При создании полинома выбирается тип коэффициентов (`1 = double`, `2 = complex`), степень и вводятся сами коэффициенты от `a[0]` до `a[deg]`. Созданные полиномы хранятся в слотах (до 16 штук) и адресуются по индексу. Ошибки ввода и операций перехватываются и выводятся как `[!] ...`.
