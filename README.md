# Четвёртая лабораторная работа по ПАТД

## Общее описание

Проект представляет собой реализацию **ленивой последовательности (`LazySequence<T>`)** на C++ с поддержкой как конечных, так и **бесконечных** последовательностей, а также **бинарной кучи (`BinaryHeap<T>`)** — очереди с приоритетами, используемой для потоковой сортировки данных.

Ленивость означает, что элементы вычисляются и материализуются **только по требованию** (при обращении по индексу) и кэшируются. Это позволяет работать с потенциально бесконечными последовательностями (натуральные числа, квадраты, степени двойки, Фибоначчи) и строить из них ленивые цепочки преобразований (`Map`, `Where`, `Concat`, …) без немедленного вычисления.

Программа предоставляет интерактивный интерфейс командной строки для построения ленивых последовательностей, применения операций над ними и сортировки потоков данных через бинарную кучу.

## Функциональность

### Операции над `LazySequence<T>`

| Операция | Описание |
|----------|----------|
| **Get / GetFirst / GetLast** | Получение элемента по ординалу-индексу (с ленивой материализацией) |
| **Append / Prepend** | Добавление элемента или другой последовательности в конец / начало |
| **InsertAt** | Вставка элемента или последовательности по индексу |
| **Concat** | Конкатенация двух последовательностей |
| **GetSubsequence** | Ленивое подмножество `[start, end]` |
| **Map** | Ленивое преобразование каждого элемента (с возможной сменой типа `T → T2`) |
| **Where** | Ленивая фильтрация по предикату |
| **Reduce / ReduceFirstN** | Свёртка всей последовательности (только конечной) или первых N элементов |
| **Take** | Материализация первых N элементов в обычную `Sequence<T>` |
| **GetLength** | Длина в виде ординала (конечная или ω) |
| **GetMaterializedCount** | Сколько элементов уже реально вычислено и закэшировано |

### Операции `BinaryHeap<T>`

| Операция | Описание |
|----------|----------|
| **Push** | Добавление элемента с просеиванием вверх (`SiftUp`) |
| **Pop** | Извлечение приоритетного элемента с просеиванием вниз (`SiftDown`) |
| **Peek** | Просмотр приоритетного элемента без извлечения |
| **GetSize / IsEmpty** | Текущий размер / проверка на пустоту |

По умолчанию используется `operator<` (минимум сверху), что при последовательном `Pop` даёт сортировку **по возрастанию**. Передав свой компаратор, можно получить сортировку по убыванию или любой другой порядок.

## Ключевые понятия

### Ординалы (`Ordinal`)

Длина ленивой последовательности может быть **бесконечной**, поэтому обычный `size_t` не подходит. Длина представляется ординалом вида `ω·a + n`:

| Запись | Значение |
|--------|----------|
| `Ordinal::Finite(n)` | Конечная длина `n` |
| `Ordinal::Omega()` | Бесконечная длина `ω` (например, натуральные числа) |
| `ω·a + n` | Сумма нескольких бесконечных и конечной части (для составных операций) |

Поддерживаются сложение, сравнение и преобразование в строку (`"omega"`, `"omega * 2 + 3"` и т.п.).

### Генераторы (`Generator<T>`)

Каждая `LazySequence` хранит указатель на `Generator<T>` — стратегию вычисления элементов. Операции (`Map`, `Where`, `Concat`, …) не вычисляют ничего сразу, а **оборачивают** исходную последовательность в новый генератор. Реальное вычисление происходит лишь при обращении по индексу, после чего результат кэшируется.

### Потоки (`Streams`)

Единый интерфейс чтения/записи данных:

| Поток | Назначение |
|-------|------------|
| `SequenceReadStream` / `SequenceWriteStream` | Чтение/запись через обычную `Sequence<T>` |
| `LazySequenceReadStream` | Чтение из ленивой последовательности |
| `StringReadStream` | Парсинг элементов из строки (через десериализатор) |
| `FileReadStream` / `FileWriteStream` | Чтение/запись в файл |

Конец потока сигнализируется исключением `EndOfStream`.

## Сортировка потока кучей

`SortStream<T>(input, output[, comparator])` полностью вычитывает входной поток в `BinaryHeap`, а затем выгружает элементы в выходной поток в порядке приоритета. Источник должен быть конечным; потоки открываются и закрываются автоматически.

```cpp
SequenceReadStream<int>  in(src);
SequenceWriteStream<int> out(dst);
SortStream<int>(in, out);                                   // по возрастанию
SortStream<int>(in, out, [](const int& a, const int& b) {   // по убыванию
    return a > b;
});
```

## Интерфейс пользователя

После запуска доступно главное меню:

```
=== Main Menu ===
1. Run demos (finite/infinite + task 10.2)   # демонстрация всех возможностей
2. LazySequence<int> operations              # интерактивные операции над последовательностью
3. Stream operations (heap sort)             # сортировка потоков бинарной кучей
0. Exit
```

- **Режим 1** — автоматическая демонстрация: конечные и бесконечные последовательности, цепочки `Map`/`Where`, Фибоначчи, операции `Append`/`Prepend`/`Concat`/`GetSubsequence`, сортировка потока кучей.
- **Режим 2** — построение и преобразование `LazySequence<int>` вручную (включая выбор бесконечных пресетов).
- **Режим 3** — сортировка введённых чисел или чисел из строки/потока бинарной кучей.

| Файл | Что проверяет |
|------|---------------|
