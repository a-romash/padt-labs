# Вторая лабораторная работа по ПАТД

## Общее описание

Проект представляет собой набор обобщённых (шаблонных) **последовательностей** на C++, реализующих единый интерфейс `Sequence<T>`. Реализованы три основных представления данных:

- **`ArraySequence<T>`** — последовательность поверх динамического массива (`DynamicArray<T>`). Доступ по индексу за **O(1)**, вставки/удаления — за **O(n)**.
- **`ListSequence<T>`** — последовательность поверх односвязного списка (`LinkedList<T>`). Вставки в начало/конец — **O(1)**, доступ по индексу — **O(n)**.
- **`AdaptiveSequence<T>`** — адаптивная последовательность, которая во время работы сама выбирает внутреннее представление (массив или список) исходя из статистики выполненных операций, перестраиваясь при превышении порога.

Каждая из `Array`- и `List`-последовательностей существует в двух вариантах — **мутабельном** (`Mutable*`, изменяет себя на месте) и **иммутабельном** (`Immutable*`, возвращает новый объект, не меняя исходный). Над любой последовательностью работают функции высшего порядка `Map` / `Where` / `Reduce` / `Zip` / `Unzip`.

Дополнительно реализована **`BitSequence`** — компактная битовая последовательность с побитовыми операциями (`AND`, `OR`, `XOR`, `NOT`).

Все контейнеры шаблонные и работают с любым типом. Программа предоставляет интерактивное меню командной строки для создания последовательностей и выполнения операций над ними.

## Функциональность

### Операции `Sequence<T>`

| Операция | Описание |
|----------|----------|
| **Get / GetFirst / GetLast** | Доступ по индексу и к крайним элементам |
| **GetLength** | Число элементов |
| **Append** | Добавление элемента в конец |
| **Prepend** | Добавление элемента в начало |
| **InsertAt** | Вставка элемента по индексу |
| **GetSubsequence** | Подпоследовательность `[start, end]` |
| **Concat** | Конкатенация с другой последовательностью (`operator+`) |
| **GetEnumerator** | Перечислитель для обхода элементов по порядку |

> У мутабельных вариантов модифицирующие операции (`Append`, `Prepend`, `InsertAt`) меняют объект на месте и возвращают `this`; у иммутабельных — возвращают новый объект, оставляя исходный неизменным. Поэтому вызывающий код проверяет `result != seq` и при необходимости освобождает старый объект.

### Функции высшего порядка (`utils/MapReduce.h`)

| Функция | Описание |
|---------|----------|
| **Map** | Применяет функцию к каждому элементу, возвращает новую последовательность |
| **Where** | Фильтрует элементы по предикату |
| **Reduce** | Сворачивает последовательность в одно значение с аккумулятором |
| **Zip** | Объединяет две последовательности в последовательность пар `Pair<A, B>` |
| **Unzip** | Обратная к `Zip` операция |

### Операции `BitSequence`

| Операция | Описание |
|----------|----------|
| **Set / Get / Flip** | Установка, чтение и инверсия бита по индексу |
| **AND / OR / XOR** | Побитовые операции с другой битовой последовательностью |
| **NOT** | Побитовое отрицание |
| **Print** | Вывод последовательности битов |

## Ключевые понятия

### Mutable / Immutable

`ArraySequence` и `ListSequence` реализованы как абстрактные базовые классы с двумя наследниками:

- **`Mutable*`** — модифицирующие операции изменяют сам объект (`GetInstance()` возвращает `this`) и возвращают `this`.
- **`Immutable*`** — модифицирующие операции клонируют объект (`Clone()`), применяют изменение к копии и возвращают её, не трогая оригинал.

Общая логика вынесена во внутренние методы (`AppendInternal`, `PrependInternal`, `InsertAtInternal`), а выбор «менять себя или копию» — в `GetInstance()`/`Clone()`. У мутабельных вариантов есть вложенный `Builder` для пошагового построения последовательности.

### Адаптивная последовательность

`AdaptiveSequence<T>` инкапсулирует указатель `inner_` на текущее представление и счётчики операций:

| Поле | Назначение |
|------|------------|
| `inner_` | Текущее внутреннее представление (`ArraySequence` или `ListSequence`) |
| `is_array_` | Какое представление активно сейчас |
| `index_ops_` | Число операций доступа по индексу |
| `insert_ops_` | Число операций вставки/добавления |

Метод `MaybeSwitch()` сравнивает счётчики: если в режиме массива вставок стало существенно больше, чем индексаций (`insert_ops_ > index_ops_ + THRESHOLD`, где `THRESHOLD = 10`), содержимое переносится в `MutableListSequence` — список выгоднее для частых вставок. Симметрично при перевесе индексаций представление возвращается к массиву. Так структура подстраивается под фактический профиль нагрузки.

### BitSequence

Биты упакованы в массив `char` (`byteCount_ = (length_ + 7) / 8`), что экономит память по сравнению с хранением каждого бита в отдельном `int`. Доступ к биту — через маску внутри байта. Побитовые операции есть в двух формах: с записью результата в переданный объект (`AND(other, result)`) и через перегруженные операторы (`operator&` и др.).

## Интерфейс пользователя

После запуска доступно главное меню:

```
==== Lab 2 - Sequences ====

=== Main Menu ===
1. Work with Sequence<int>
2. Work with BitSequence
0. Exit
```

При работе с последовательностью сначала выбирается её тип и вводятся элементы:

```
=== Select Sequence Type ===
1. MutableArraySequence<int>
2. MutableListSequence<int>
3. ImmutableArraySequence<int>
4. ImmutableListSequence<int>
5. AdaptiveSequence<int>
```

Затем доступно меню операций над последовательностью:

```
=== Sequence Operations ===
Current: [ ... ]            # текущее содержимое
1.  Get element by index
2.  Append
3.  Prepend
4.  InsertAt
5.  GetSubsequence
6.  Concat with new sequence
7.  Map (x * 2)
8.  Where (even only)
9.  Reduce (sum)
10. Zip with new sequence
11. GetFirst / GetLast
12. GetLength
0.  Back
```

Для `BitSequence` предусмотрено отдельное меню (`Set` / `Get` / `Flip` / `AND` / `OR` / `XOR` / `NOT`). Ввод проверяется на корректность (повтор при ошибке), а исключения операций (выход за границы, пустая последовательность и т.п.) перехватываются и выводятся как `Error: ...`.
